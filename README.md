## Instalation

### Prerequisites

- Rust 1.80 or higher
- Cargo (comes with Rust)

## Usage

Run the app

```bash
cargo run --release
```

The program will:

- Move your cursor by 10 pixels every 60 seconds
- Keep your computer from going to sleep
- Run continuously until stopped with Ctrl+C
